1 Dashboard Page

1
Click "🏠 Dashboard" in sidebar
The dashboard should load immediately showing 6 metric cards.
✓ EXPECT: Delayed POs = 2  |  System Status = ✅ Live
2
Click "⚡ Simulate Inbound Event" button
This fires a POST to /api/demo/simulate and injects a supplier delay event into the orchestrator pipeline.
✓ EXPECT: Button shows "⚙️ Processing…" briefly, then Pending Approvals counter increments to 1
3
Check Live Feed panel (bottom of sidebar)
After simulate, the Live Feed should show a new real-time WebSocket event pushed from the backend.
✓ EXPECT: New entry appears in Live Feed within 2 seconds
4
Check Event Status Breakdown card
Should now show awaiting approval with count 1.
✓ EXPECT: "awaiting approval 1" in event breakdown

2 Events Page

5
Click "⚡ Events" in sidebar
Should show a table of all orchestration events. After the simulation you'll see at least 1 event.
✓ EXPECT: Table with 1+ rows, status badge awaiting approval
6
Click the ✅ Approve button on the event
This fires POST /api/orchestrator/events/:id/approve and moves the event to approved status.
✓ EXPECT: Row status changes to approved immediately
7
Simulate a second event, then Reject it
Go back to Dashboard → click Simulate again → go to Events → click ❌ Reject on the new event. Enter a rejection reason when prompted.
✓ EXPECT: Row status changes to rejected
8
Filter events by status
Use the status filter dropdown (if shown) or check that all events are listed with correct status badges.
✓ EXPECT: Filter works, showing only events of selected status
