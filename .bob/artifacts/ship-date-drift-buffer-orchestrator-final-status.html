Run Commands

Run All Tests

cd app/adk && .venv/bin/pytest tests/ -v # 63 ADK Python tests cd app/backend && npm test --forceExit # 43 Node.js tests

Start Dev Stack

./start-dev.sh # tests + backend :4000 + frontend :3000 # OR individually: cd app/backend && npm start # :4000 (REST + WebSocket) cd app/adk && adk web # :8000 (ADK dev UI) cd app/frontend && npm start # :3000 (React dashboard) # OR via Docker Compose: cd app && docker compose up --build

Deploy to Vertex AI Agent Engine

cd app/adk python deployment/deploy_agent_engine.py \ --project gen-lang-client-0692958287 \ --location us-central1
⚠️ ADK deprecation warnings (not failures): SequentialAgent and ParallelAgent are deprecated in ADK 2.6.3 in favour of Workflow, but Workflow cannot yet be used as an LlmAgent sub-agent. Migration will be possible in a future ADK release.
